same-text protocol and scoring concepts in project 2026-012.

task identifier, constraints, source digest and output contract. The new runner
envelope is explicitly different. The original generator is never rebranded as
the new SHA-256 generator. No historical scientific output is silently replaced.

original environment, not live results from this repository. The old corpus
has nested lengths and short-period parameter patterns. Preserve null findings.

importing TypeScript or Mirai. Agreement tests establish implementation agreement,
not independence of authorship or mathematical proof of all possible inputs.
