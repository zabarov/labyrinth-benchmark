# Implementation status - 2026-09-07

Local 0.1.0 implementation accepted for offline use and live-pilot preparation.
This is not a published release or cross-platform certification. A separately
authorized real-model feasibility pilot is now complete; it did not establish
an overall advantage for Mirai or working memory. Follow-up diagnostics establish
one real warm-cache reuse and correct generated programs, not overall superiority.
See [latest findings](autonomous-live-findings.md) and the preserved
[historical pilot](live-pilot-findings.md).

## Implemented and locally checked

  legacy generation, three tracks, six memory phases, strict result admission.
- Recorded, HTTP, JSONL and optional public-API Mirai participant surfaces.
- Root reservations, trial-scoped usage, uncertain response handling, durable
  journals, conservative resume and cancellation tests.
- Strict report schema, JSON/Markdown reporting and allowlisted reproduction
  metadata export. Unknown usage remains unknown; failures remain assigned.
- Native Mirai TaskHost/Cognition/compiler/Runtime and Files memory composition.
  No evaluator or oracle is imported by that composition.

  program receiver and records each inference turn independently. Integration
  passed with a real local Docker tool and recorded model responses, including
  missing-tool and unauthorized-tool rejection. Post-pilot core suite is 28/28
  PASS, including explicit reasoning-model transport parameters.
- A recorded native program computes all ten transitions correctly. A wrong
  program is rejected. Six memory phases exercise reuse, invalidation, isolation
  and revoked access. These are integration tests, not model-quality evidence.
- A 1000-layer input reaches the native provider boundary unchanged. Its recorded
  wrong output remains a failure; this is not a 1000-layer solution claim.
- Fresh source-only macOS reproduction with Node 22.23.2 and Python 3.12.12:
  offline install, build, 27 core tests, CLI run, report and export. Six recorded
  demo phases match the oracle. The owned temporary directory is removed.
- Docker checks cover absent host mounts/secrets, blocked network and image
  writes, excessive output, and cancellation. These require a locally available
  digest-pinned image and are separate from core tests.

## Post-pilot adapter correction

- Plain prompts expose only authorized tools, and an undeclared tool cannot be
  used just because a host implementation exists.
- Mirai receives an authored-source projection and a compiler-checked generic
  addition example. The public compiler still rejects a forged supplied digest.
- Native cancellation now reaches the HTTP call. Inference follows the root
  time allowance; pure program execution retains its separate bounded duration.
- The authoring-reference digest is bound to memory processor identity, so a
  changed language guide cannot silently reuse an old extraction projection.
- Core regressions: 32/32 pass on Node 22 and Node 24. Native compiler/runtime
  integration passes locally; a delayed recorded provider verifies that a
  31-second response is admitted under a 40-second host allowance.
- All 418 historical campaign files remain byte-identical. No paid calls were
  made by the correction batch. A new live result must use a separate frozen
  configuration and cannot overwrite the negative pilot.
