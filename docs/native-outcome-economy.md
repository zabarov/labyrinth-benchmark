## Implementation

inventory example to describe data-driven Programs. The participant receives
the same task text as the plain condition. No maze parser, route or oracle is
provided to it. The model still authors the actual operations and data.

The native Cognitive Kernel awaits isolated pure candidate execution and checks
the requested result protocol before accepting generation. Compiler, runtime
and protocol defects feed its existing bounded correction path. Successful
trial execution is reused for delivery rather than executed twice. Cached
candidates are executed and checked again under current task access.

The final native TaskHost records Outcome admission before returning a result.
Checks cover the requested status, full trace cardinality, integer transitions,
valid branch labels, continuity and whether the returned value corresponds to
the requested goal. These checks do not parse the source or compute an expected
route. A self-consistent but invented trace can pass protocol admission; the
independent evaluator still rejects it. The first diagnostic recorded
`semantic_acceptance: false`; the newer source-reviewed candidate is described
below and must not be confused with that historical protocol-only result.

# Source-Grounded Review Candidate

The default composition now adds a governed reviewer task through installed
`createTaskSemanticPreparationReceiver` and `createSemanticTaskHost` APIs.
Generation, compiler/protocol corrections and source review share one TaskHost
root ledger. The reviewer sees the original text, requested goal and executed
result. The initial reviewer also received the entire generated program; the
next candidate replaces that redundant copy with its bound candidate digest.
All result criteria remain unchanged. No evaluator route or parser is imported.

The Outcome contract is fixed before generation. A negative, uncertain, missing
or over-budget review blocks delivery. Warm memory supplies a candidate only:
execution and source review run again with current access and dependencies.
Replay recomputes recorded admission without calling a provider. The source
review uses a separate role of the same fixed model, not an independent human,
and its decision can be wrong. Exact correctness remains independently scored.

The explicit `review: protocol` constructor option preserves a diagnostic control
for historical harness tests. It is not the live default and artifacts identify
its weaker acceptance. Source-reviewed `matched_tools` currently fails before
inference with an incompatibility diagnostic: Python tool turns have not yet
been connected to this shared reviewer ledger. Do not present that mode as
implemented or silently substitute protocol-only execution.

Source disagreement currently yields a recorded incomplete result. Compiler and
protocol defects use native bounded correction. Source-directed refinement is
not yet integrated by this participant; that limitation remains visible.

Artifact directories are allocated atomically, including after participant
re-open, so new attempts cannot overwrite older evidence. Unsupported review
modes are rejected before inference. These are local candidate changes, not a
published release or an independent security certification.

Review decisions must now explain negative or uncertain verdicts. An empty
negative decision fails a deterministic diagnostic check and may receive one
native corrective attempt under the same root budget. A nonempty explanation
is not proof that the reviewer is right; independent evaluation still measures
false acceptance and false rejection. No evaluator answer is fed into review.
